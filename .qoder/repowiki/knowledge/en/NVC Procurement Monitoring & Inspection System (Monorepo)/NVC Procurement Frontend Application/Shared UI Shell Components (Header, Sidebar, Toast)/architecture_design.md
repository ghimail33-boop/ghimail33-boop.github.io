Three independent presentational React components under `src/components/`:
- `Header.tsx` is a stateless functional component consuming `AuthContext` (`useAuth`) to display the app title, current user badge, and a demo role-switcher that calls `switchRole('admin'|'inspector'|'reviewer'|'public_officer')`; it receives `onSearch` and `activeView` as props from its parent.
- `Sidebar.tsx` is a controlled navigation component driven by an external `currentTab` / `onSelectTab` prop pair; navigation items are declared as a local `navItems` array of `{id, label, sublabel, icon, badge?, badgeColor?}` entries, enabling declarative menu configuration without internal state.
- `Toast.tsx` implements a provider/consumer pattern: `ToastProvider` owns toast state via `useState` + `useRef` for unique IDs, exposes `showToast(type, title, message?)` through a React `Context`, and renders a fixed bottom-right container capped at four concurrent toasts with auto-dismiss timers (6.5s for errors, 4.2s otherwise). Consumers call `useToast()` which throws if used outside the provider.
Dependency direction is one-way: Header depends on `../context/AuthContext`; Sidebar and Toast have no cross-component dependencies, making them reusable across views.
