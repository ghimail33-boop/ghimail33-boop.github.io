The module is organized as a thin shell around the rest of the app. `src/main.tsx` is the single entry point that creates the React 18 root via `createRoot`, wraps the app in `StrictMode`, imports global styles from `index.css`, and renders `<App />`. `src/App.tsx` defines the default export `App`, which composes three provider layers — `AuthProvider` (from `./context/AuthContext`) for auth state, `ToastProvider` (from `./components/Toast`) for notifications, and then the `MainApp` component. `MainApp` owns all cross-cutting UI state: current tab (`dashboard | procurements | inspections | findings | corrective-actions | master-checklist | reports | audit-logs`), badge counts fetched from `api.getDashboardSummary()`, modal visibility flags, and navigation parameters passed down to child views. It renders a fixed `Header` plus a responsive two-column layout (`Sidebar` + `main` content area) and conditionally mounts one of eight view components based on `currentTab`. Modal dialogs (`ProcurementModal`, `FindingModal`, `EvidenceModal`, `ReportPrintModal`) are rendered at the bottom of the tree and driven by local state lifted up from their respective views. `src/index.css` sets up Tailwind CSS v4 (`@import "tailwindcss"`), applies the Mukta font family, defines print-media rules (`no-print`, `print-only`, `page-break`), custom scrollbars, and keyframe animations for toasts and checklist item highlights.
