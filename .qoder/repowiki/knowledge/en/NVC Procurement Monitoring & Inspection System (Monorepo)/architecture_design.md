The root `server.ts` is the single entry point: it bootstraps Express, mounts every domain router under `/api/*` (auth, master, procurements, checklists, inspections, findings, corrective-actions, evidence, dashboard, reports, audit-logs), initializes the shared database via `initDb()` before any request handling, and in development proxies Vite's HMR middleware while in production serving the built `dist/` SPA. The frontend (`index.html` + React app) and backend live side-by-side; the client calls the same host's `/api/*` endpoints, so deployment is a single Node process rather than two separate services. A bundled `data/pgdata/` directory provides an embedded PGlite instance alongside an optional external PostgreSQL, letting the whole system run without an external DB server.
